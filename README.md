# 教材 3D 实验室 · textbook-3d-lab

把一句「给我讲讲动能」变成**一个能拖、能调、能离线双击运行**的 3D 课件。

不是把教材插图做成 3D 模型摆着看，而是让抽象概念**看得见变化过程**：斜面上的球滚下去、压强随深度涨、杠杆平衡被打破的那一刻。

---

## 这是什么

仓库里有两个可以独立使用的部件：

| 部件 | 位置 | 说明 |
|---|---|---|
| **生成器（Skill）** | [`skill/`](skill/) | 输入一个知识点，输出**单文件 HTML 课件**。双击即开，不需要服务器、不需要教材 PDF、不依赖任何外部资源 |
| **实验站（Lab）** | 根目录 | 37 个已完成的 3D 实验 + 可翻页的教材阅读器 + 教材目录面板 + 笔批注。用真实书页当底座，装置悬空立在纸面上 |

两者的渲染管线是同一套（同一份视觉配方），Skill 是把它抽成了可复用的模子。

## 快速上手

### A. 生成一个课件（3 分钟）

```bash
# 1. 把 skill/ 复制到你的技能目录
cp -r skill ~/.workbuddy/skills/textbook-3d-lab

# 2. 在对话里说：做一个动能的 3D 实验
#    Skill 会定位知识点 → 写场景 → 打包 → 无头浏览器自检 → 交付

# 3. 也可以直接用命令行打包已有的场景
python skill/scripts/build.py skill/assets/examples/kinetic.scene.js -o 动能.html --embed-three
```

`--embed-three` 会把 three.js 一起内联，产物约 1.7 MB，**完全离线**；不加则是 38 KB，走 CDN。

### B. 跑实验站

```bash
python serve.py 8123     # 纯静态服务，带 no-store 头避免改代码后浏览器吃缓存
# 打开 http://127.0.0.1:8123/
```

> 实验站需要自备教材 PDF，放在 `books/` 下（结构见 `.gitignore` 注释）。**仓库不附带任何教材文件**，原因见文末版权说明。

### C. 动态书架（可选）

```bash
cd server
node --experimental-sqlite seed.js     # 扫描 books/ 入库：学段/年级/学科/版本/册次
node --experimental-sqlite api.js 8200 # 书架 API + PDF Range 流式读取
# 打开 http://127.0.0.1:8200/
```

书架按「小学 → 初中 → 高中」贯通，每本书带状态标记（待下载 / 已下载 / 有目录 / 有 3D）。

## 已完成的 37 个实验

以人教版物理八年级下册为蓝本（第 7~12 章，96 页，22 节）。

**核心实验 · 抽象概念 · 公式推演**

| 章节 | 实验 |
|---|---|
| 第 7 章 力 | 弹力 F=kx、重力 G=mg、推门 A/B/C 三要素 |
| 第 8 章 运动和力 | 牛顿第一定律（斜面小车 + 阻力调节 + 推理链）、二力平衡、滑动摩擦、甩橡皮 |
| 第 9 章 压强 | 海绵压陷 p=F/S、液体压强 p=ρgh 三孔喷水、U 形管压强计、覆杯、托里拆利、自制气压计、硬币跳高、机翼模型、吹纸 |
| 第 10 章 浮力 | 浮力=上下表面压力差、阿基米德 F浮=G排、浮沉条件、橡皮泥小船、热气球 |
| 第 11 章 功和机械能 | 功、功率、动能 Ek=½mv²（三步推理链）、重力势能、弹性势能、单摆守恒、滚摆、水电站能量流、烧水、摩擦生热 |
| 第 12 章 简单机械 | 杠杆 F₁L₁=F₂L₂、定/动滑轮、斜面机械效率、动滑轮省功 |

每个实验都满足三条硬标准：**参数可调**、**有实时读数**、**有推理链标签**（公式是"长出来"的，不是贴在屏幕上的）。

## 视觉配方

对着「铜匠实验室」的成品逆向过一遍，好看不是靠模型精细，是靠这几条：

- **哑光陶土材质**：`metalness = 0`、`roughness 0.62`、极薄 clearcoat —— 不是油亮塑料
- **冷天光 + 暖地光**：程序化生成环境贴图（canvas → PMREM），上冷蓝、地平线暖沙，和纸页融为一体
- **五灯布光**：主光 2048 软阴影 + 冷补光 + 轮廓光 + 底部反弹，物体边缘有高光钩边
- **ACES 色调映射**：高光滚降，避免死白
- **全场景圆角**：`ExtrudeGeometry` + bevel 替代硬边方盒
- **淡雾**：`Fog(0xf3efe4, 16, 46)` 让远景自然融入

自动取景器（`autoFrame`）会在每课载入时把装置包围盒投影到屏幕，越界就自动后拉居中——所以 37 个场景不用逐个手调相机。

## 目录结构

```
textbook-3d-lab/
├── skill/                    # 生成器：一个知识点 → 单文件 HTML
│   ├── SKILL.md              # 工作流与契约
│   ├── assets/runtime/       # lab.js（渲染管线）+ template.html（外壳）
│   ├── assets/examples/      # 黄金样例：动能
│   ├── references/           # 场景编写规范 + 知识点索引
│   └── scripts/build.py      # 打包器
├── js/
│   ├── stage.js              # 渲染管线（材质/灯光/环境/取景器）
│   ├── book.js pdfpages.js   # 书页渲染与翻页动画
│   ├── scenesA~D, scenesBuoy # 37 个场景
│   └── app.js                # 主控：目录、拖拽、笔、取景
├── assets/style.css
├── index.html                # 实验站（阅读器）
├── shelf.html                # 书架
├── server/                   # SQLite 数据模型 + API + 导入器
└── serve.py                  # 静态服务（no-store）
```
