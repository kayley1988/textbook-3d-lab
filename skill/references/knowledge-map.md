# 知识点索引（跨版本通用）

> 定位原则：**知识点是唯一的锚**。教材版本和页码只是查询入口。
> 用户给页码 → 在下表查到知识点 → 按知识点生成。
> 表里没有的版本 → 用知识点名向用户确认，不要凭空猜页码。

## 使用方式

| 用户输入 | 处理 |
|---|---|
| "做一个动能实验" | 直接命中知识点 `mech.kinetic` |
| "人教版八下 P71" | 查「人教版·物理八下」表 → P71 对开 → `mech.kinetic` |
| "八年级上 第三章" | 查对应版本目录 → 该章知识点清单，向用户确认做哪些 |
| 版本不在表里 | 请用户告知节标题或知识点名（版本表按需扩充） |

  按节标题映射到上表知识点，然后把「版本+页码」补进本文件。
